# Individual contributions

See [team ownership](docs/TEAM.md), the maintained
[path/commit manifest](docs/team-responsibilities.json), and each record under
`individual-contributions/`. The five module import commits use the authorized
author emails; the actual pusher/coordinator is recorded separately as committer.
Generated runtime/deployment/docs integration is a separate Praneeth commit.

Run `npm run verify:submission` to check real paths, exported-function anchors
and recorded author emails when Git history is available. This structural check
does not establish semantic correctness or prove who originally wrote source.
The coordinator's confirmation is the attribution basis. Do not infer equal
effort from counts or attribute future work merely from an ownership plan.
Historical contribution documents are preserved under `legacy/` for reference.
